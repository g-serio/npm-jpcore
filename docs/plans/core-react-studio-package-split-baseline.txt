Baseline snapshot — ADR-0016 / core-react-studio-package-split plan, Task 0.1
Captured: 2026-07-16 (repo: npm-jpcore, branch at capture time as checked out)

Environment note: this WSL Ubuntu instance has no native Linux node/npm on
non-interactive PATH by default (bash -lc does not source ~/.bashrc's nvm
init in a way that survives, and $HOME is unset in that context). A native
Linux node v24.13.0 (npm 11.6.2) IS installed via nvm at
/home/dev/.nvm/versions/node/v24.13.0 and must be activated explicitly:

  export HOME=/home/dev
  export NVM_DIR=/home/dev/.nvm
  source /home/dev/.nvm/nvm.sh
  nvm use 24

Without this, npm/node resolve to a Windows-side nvm4w shim via WSL
interop (/mnt/c/nvm4w/nodejs/npm), which cannot run this repo's
node_modules (installed with POSIX symlinks) and fails on UNC-style
cwd translation for lifecycle scripts (spawns cmd.exe, which prints
"UNC paths are not supported. Defaulting to Windows directory.").
Record this so later phases don't re-lose the same hour to it.
